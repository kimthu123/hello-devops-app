# 👋 Hello DevOps App

A simple DevOps learning project built with Bash and Git.  
This project marks the beginning of my DevOps journey — learning Linux, WSL2, Git workflows, automation, and eventually Docker, CI/CD, and cloud infrastructure.

---

## 🚀 What This App Does

This small Bash script demonstrates DevOps fundamentals:

- Prints **username**, **current date/time**, and **working directory**
- Shows how to create & run executable scripts in Linux
- Demonstrates Git basics: **commits**, **branches**, **merges**
- Sets the foundation for future DevOps practices (automation, CI/CD pipelines, containerisation, etc.)

---

## ▶️ How to Run Locally

```bash

chmod +x main.sh
./main.sh
```

You should see your username, current time/date, and working directory printed to the terminal.
